# 09: Settings usability and splash assets

## Problem
With several settings sections expanded, the bottom of the Settings screen was unreachable on small phones. The splash and launcher assets were leftovers from the prototype.

## Goal
Make every setting reachable, and replace the visual assets.

## Scope
- Scrollable Settings layout
- New glycemia vector drawable and splash background; unused launcher images removed

## Out of scope
- Restructuring settings content

## Acceptance criteria
- [x] All settings are reachable with every section expanded on a small screen
- [x] The splash screen uses the new assets
